Support AsyncAPI 3 Multi Format Schema Objects (`{ schemaFormat, schema }`) for message `payload` and `headers`, as generated by tools such as Springwolf. Schemas in an AsyncAPI or JSON Schema format (any version) are now unwrapped and validated; previously the wrapper was treated as an empty schema and every message silently passed. Unsupported formats (e.g. Avro, Protobuf, RAML) now emit a `message.payload.unvalidatable` or `message.headers.unvalidatable` warning instead of passing silently.
